# Chocolate_sales_analysis
# About the project
This project utilizes SQL to analyze a dataset of chocolate sales across different countries and products. The queries address the following questions:
- Revenue by country
- Monthly revenue trend
- Salesperson performance
- Products by Revenue and Units
- Sales Rep  performance
- Revenue of boxes 

# Built With
- SQL
- Tableau
- Claude
